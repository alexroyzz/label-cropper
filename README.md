# Label Cropper - Flipkart & Meesho, 4x6 thermal labels

100% frontend (React + Vite). All PDF processing happens in the browser with pdf.js + pdf-lib.
There is no backend, database or API: your PDFs are never uploaded anywhere.

Flow: PDF chosen in the browser -> pdf.js reads the text -> Flipkart/Meesho label detection ->
pdf-lib crops (original vectors, no resampling) -> generated PDF shown in the browser's native
PDF viewer -> Download / Print.

## Run
    cd client
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # prerendered static files in client/dist, static files ready for Hostinger or any static host

The production build renders the homepage, marketplace guides, and tutorial into static HTML before deployment, then hydrates each page in the browser. Vite copies files such as `robots.txt` and `sitemap.xml` from `client/public` to the output root. Deploy by uploading the contents of `dist/` (including the hidden `.htaccess`) to `public_html` on Hostinger, or by connecting the GitHub repository in hPanel (Git deployment) with build command `npm run build` and output directory `dist`. `public/.htaccess` serves each prerendered route, keeps URLs without a trailing slash, and returns a real 404 for unknown URLs.

## Crop calibration
Both platforms are auto-detected from the page text (see `client/src/labelLogic.js`).
`DEFAULT_PRESETS` in `client/src/presets.js` (x/y/w/h as fractions of the page, y from the top)
are only the fallback used when auto-detect is off or fails; they can also be tuned live in the
"Fine tune crop area" box.

## SEO and multi-language blog
- Domain constant: `src/site.js` (`https://croplabelfree.online`). Canonical URLs, JSON-LD, sitemap and robots all use it.
- Marketplaces: `src/platforms.js` (Meesho and Flipkart auto-detect; a newly added marketplace can use the manual crop area until its layout is measured in `labelLogic.js`).
- Per-platform guides + FAQ in 14 languages (English, Hinglish, Hindi, Bengali, Marathi, Telugu, Tamil, Gujarati, Kannada, Malayalam, Punjabi, Odia, Assamese, Urdu): copy lives in `src/langs/`, pages are generated by `src/guides.js`.
- URLs: `/blog/<lang>` (language hub) and `/blog/<lang>/<platform>-label-cropper`; English guides are `/blog/how-to-crop-<platform>-shipping-label-pdf`.
- `npm run build` prerenders every page (with hreflang alternates and FAQPage schema) and regenerates `dist/sitemap.xml`.

## llms.txt
`npm run llms` regenerates `public/llms.txt` and `public/llms-full.txt` from the site's own page data. Every link in them points to `https://croplabelfree.online`. Re-run it after adding pages.
